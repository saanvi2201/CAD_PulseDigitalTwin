# CAD Digital Twin — Setup Guide

## 1. Project Overview

This repository contains the CAD Digital Twin implementation combining:

1. Genomic risk information / PRS
2. Lifestyle ML risk prediction
3. Clinical ML risk prediction
4. Calibration and explainability
5. Pulse Physiological Engine integration
6. Exercise / physiological validation

The ML risk layer and physiological simulation layer are kept separate.
